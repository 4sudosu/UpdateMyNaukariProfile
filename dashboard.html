How to get session cookies — step by step
Step 1. In Chrome or Edge, log in at naukri.com (Google login works too).
Step 2. Press F12 → open the Application tab → expand Cookies → click https://www.naukri.com.
Step 3. Find nauk_at → double-click its Value → copy. This one is required.
Step 4. Same for nauk_sid and nauk_rt (recommended — keeps the session stable).
Step 5. Paste everything above as one line (nauk_at=...; nauk_sid=...; nauk_rt=...) or fill the three boxes.
Step 6. Click Add profile — the server verifies the cookies instantly and tells you if they are expired.
Later: cookies expire after some days/weeks — when updates start failing, paste fresh ones via “Refresh login” on the profile card.

Shortcut — paste this in the Console tab and copy the printed lines:
["nauk_at","nauk_sid","nauk_rt"].forEach(n=>{const v=document.cookie.split("; ").find(r=>r.startsWith(n+"="));console.log(n+"="+(v?v.split("=").slice(1).join("="):"(not readable here — copy it from the Application tab)"))});
Note: if a cookie is HttpOnly, document.cookie hides it — copy that one from the Application tab in Step 3.
